# Problem-Type Notebook Suite

**Status:** superseded by the current development scope

This page is kept only for older issue links. The active notebook direction now
lives in [../developing-features](../developing-features.md) and [../notebooks](../notebooks.qmd).

Current notebook work has two jobs:

- demonstrate SGB geometry semantics with one geometry-route contract per
  notebook;
- demonstrate `gsim` Resolve/Results with public Palace analysis packages.

The notebook suite should not define a third development capability. It is a
consumer surface for SGB and `gsim`, not a separate solver or report layer.
